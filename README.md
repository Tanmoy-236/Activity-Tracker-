# Activity Tracker

A modern, cross-platform activity tracker for managing daily activities, tasks, goals, and productivity.

## Planned features

- Daily activity and task tracking
- Goals and recurring tasks
- Calendar and progress analytics
- Offline-first functionality
- Local data storage with automatic cloud synchronization
- Data backup and recovery
- Responsive desktop and mobile experience

## Development status

**Status:** Initial development — Phase 1 (project foundation).

The application is being developed incrementally. Features and architecture may evolve as implementation and testing progress.

## Planned technology stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express
- Local database: SQLite
- Browser-side storage: IndexedDB
- Offline support: Service Worker
- Charts: Chart.js

## Development environments

Ubuntu on Android and Windows.
